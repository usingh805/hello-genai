# Weekly Status Report Instructions

- Output format: Markdown.
- Use these sections in this order: `Accomplishments`, `Blockers`, `Next Week`.
- Use bullet points only for all report content.
- Keep the complete report to a maximum of 20 lines.
- Use a professional, direct tone.
- Remove fluff words, filler, greetings, and unnecessary commentary.
- Include only specific, actionable status information.
