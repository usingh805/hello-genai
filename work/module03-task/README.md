# Python Calculator

A simple Python calculator project with functions for addition, subtraction, and multiplication.

## Multiply

The `multiply(first_number, second_number)` function returns the product of two numbers:

```python
from calculator import multiply

result = multiply(6, 7)
print(result)  # 42
```

## Run the example

From this directory, run:

```bash
python3 main.py
```

The program prints the results of adding, subtracting, and multiplying two numbers.
